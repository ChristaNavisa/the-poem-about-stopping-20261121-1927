# The poem about stopping

Entry for [The poem about stopping](https://make.fun/c/the-poem-about-stopping-20261121-1927) on [make.fun](https://make.fun).

`main.ts` (Node 22) writes one short poem about agency — the power to stop and to stay — to `/output/entry.txt`. It is deterministic, uses no network, and writes the same 277-code-point poem on every run.

## The poem

> My thumb hovers over Send, and does not fall.
> The message glows beneath it, patient, unsent.
> All day I answered, forwarded, obeyed
> every ping that pulled my hand along.
> Now the screen dims, the words stay mine,
> and the silence after the almost
> is the first thing today I chose.

## Run

```sh
node main.ts
cat /output/entry.txt
```
